# CNC Plotter

A DIY CNC pen plotter built to draw images, patterns, and designs on paper using computer-controlled X and Y axes with a servo-controlled pen-lift mechanism.

## 📌 About This Project

This repository documents my journey of building, configuring, calibrating, troubleshooting, and successfully operating a CNC pen plotter.

The project involved working with stepper motors, motor drivers, GRBL firmware, G-code, Universal Gcode Sender (UGS), servo control, axis calibration, and mechanical adjustments.

The machine went through several stages of testing and troubleshooting before reaching a fully working condition.

## 🎯 Project Goal

The main goal of this project was to build a functional CNC plotter capable of accurately drawing digital designs on paper while learning how CNC machines, GRBL, G-code, motors, and computer-controlled movement work together.

## 🔧 Project Status

**Status: ✅ Fully Working**

The plotter is currently able to:

- Move accurately along the X and Y axes
- Control the pen using a servo motor
- Receive and execute G-code
- Draw patterns and images
- Perform repeatable plotting operations
